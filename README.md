# Nome do projeto
CineLog - Diário de Filmes e Séries

# Integrantes
* Gabriel Rockenbach Giovanela (Desenvolvimento individual)

# Descrição da proposta
O CineLog é um aplicativo para cadastro, avaliação e acompanhamento de filmes e séries assistidos. O sistema conta com 4 telas principais:
1. Tela de Login (autenticação)
2. Lista de Filmes e Séries (exibição dos cadastros)
3. Formulário (criação e edição de registros)
4. Tela de Detalhes (visualização completa e exclusão)

Os dados são armazenados localmente com operações completas de CRUD (Create, Read, Update, Delete).

# Tecnologias utilizadas
* Linguagem: Kotlin
* IDE: Android Studio
* Interface: Layouts XML (Activities e Fragments)
* Persistência de Dados: Room (SQLite)
* Controle de Versão: Git e GitHub

# Instruções de execução
1. Clone o repositório:
   git clone https://github.com/GabrielG2155/cinelog.git
2. Abra o projeto no Android Studio.
3. Aguarde o término da sincronização do Gradle.
4. Execute o projeto em um emulador (AVD) ou dispositivo físico via USB (Shift + F10).
